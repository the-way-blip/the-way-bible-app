# thewaybible.app
# Everything except the internal API is open to crawlers, including the
# assistant crawlers. The AI bots are named explicitly below so the intent
# is on the record rather than inherited from the wildcard group.
#
# /api/og is the Open Graph image for every verse and topic page. It stays
# open to crawlers on purpose — Search Console showed 33 of them reported as
# "Blocked by robots.txt", which means Google could not fetch the preview
# image for those pages. Everything else under /api/ is internal.
#
# /read/ is the in-app reader (a JavaScript shell whose canonical is the
# homepage). Every verse page links to it, so leaving it open spends crawl
# budget on ~31,000 duplicate-of-home URLs. The indexable text lives at
# /bible/<book>/<chapter>/<verse>.
